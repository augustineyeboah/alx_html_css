# Headphones Website – HTML & CSS Project

This project is part of the ALX Front-End curriculum. The objective is to recreate a responsive webpage based on a Figma design. The final result must closely match both the desktop and mobile layouts.

---

## 🔗 Figma Resources

To access the design:

1. Create or log into your Figma account.
2. Open the project link provided in the instructions.
3. Click **“Duplicate to your Drafts”** to copy the design.

If you're unable to open the link, use the downloadable Figma file provided separately.

### Required Fonts
If your computer doesn’t have the fonts used in the design, download and install:

- **Source Sans Pro**
- **Spin Cycle OT**

---

## 🎯 Project Requirements

### Responsive Design
- The page must automatically switch to the **mobile version** when the screen width is **480px or less**.
- The **maximum width** of the main content is **1000px**, centered on the page.

### Interactions
- **Links hover/active color:** `#FF6565`
- **Button hover/active:** `opacity: 0.9`

### General Notes
- Follow the spacing, typography, and colors shown in the Figma design.
- Some Figma values are in decimals — rounding them is acceptable.
- Ensure your HTML structure is clean and semantic.
